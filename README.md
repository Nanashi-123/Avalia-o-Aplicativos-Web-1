Após estar dentro da página do projeto, execute o comando - npm install - para instalar as dependências do npm

Depois execute o - npm run dev - para abrir a página no navegador

A route funciona por meio do pacote de rotas do npm - react-router - e, para ele funcionar- é preciso configurar as rotas que definem qual arquivo.jsx será carregado na index.html (pois react usa single page aplication). Nesse caso, as rotas foram configuradas no app.jsx.
